## Overview

Initially intended for a workshop for my club, I wanted to create a personal portfolio as a way to establish a digital identity. My first iteration was poorly executed and over-engineered. Also I wanted to keep things simple and clean for the visitor. The design was inspired by [Matthew Ao's](https://matthewao.com/) portfolio. I had done my own polishing and personal additions to make the website feel nicer.

## How it works

Built with Next.js 16, React 19 and Tailwind CSS v4. Posts and projects are plain Markdown files read at build time. Obsidian markdown uploads are automatically deployed onto the website using a YAML script and GitHub Actions for the sake of my convenience.

## What I learned

This would be my first project with Claude's skills. Utilizing these skills made frontend implementations simplified. The problems I faced when developing my first portfolio was that Frontend is really really messy. I do not enjoy reading HTML, CSS, and Typescript. Even if it's in React or Tailwind. The skills Claude used actually made it pleasing to look at. I would have never figured out the proper implementation principles because I would be to busy being frustrated how ugly the code looks.

For this project, I had realized how powerful Claude Skills are (or any Agentic skill). It is essentially importing a library of principles rather than code. You don't have to worry about learning professional software design through forums, articles, and other resources as building the project itself can be the resource. It also made me think how code will be eventually unified in structure with skills. Similar to how programmers use the most optimal data structure and algorithm for a program, builders can use the most optimal skills to build a professional-grade project.
